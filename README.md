# Komentář k zákonu č. 219/1999 Sb., o ozbrojených silách České republiky

Otevřený komentář k zákonu o ozbrojených silách České republiky — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; členění a řízení ozbrojených sil, úkoly armády, Vojenská kancelář prezidenta republiky a Hradní stráž, příprava, vojenský materiál, vojenská vozidla a letecká technika, použití vojenské zbraně, náhrada škody a evidence.

Konsolidované znění: dokument e-Sbírky `SB-1999-00219_2025-07-01`.
